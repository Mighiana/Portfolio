BlastRadius

Compares Terraform snapshots and explains newly reachable paths to sensitive cloud resources using supported AWS relationships.

Private beta · Render

  • Python
  • FastAPI
  • React
  • Terraform
  • GitHub Actions

Technical evidence chain

  1. Terraform change
  2. →Infrastructure graph
  3. →New reachability path
  4. →Security impact
Problem
A Terraform diff shows what changed, not what became reachable. A small change can open a new path to a sensitive resource.
What I built
A Terraform security-analysis tool that compares infrastructure changes and identifies newly introduced attack and reachability paths to sensitive AWS resources. It models supported cloud relationships as an infrastructure graph and produces explainable SAFE TO MERGE, REVIEW REQUIRED and BLOCK CHANGE decisions with supporting evidence, plus JSON, Markdown and SARIF reports for command-line, CI and pull-request security review workflows.
Architecture
React / TypeScript → FastAPI → SQLAlchemy with PostgreSQL (SQLite locally). Isolated background jobs run the Python analysis engine.
Implementation
Infrastructure graph construction, IAM normalization, attack-path search, findings, remediation guidance and JSON / Markdown / SARIF exports; CLI and GitHub PR checks.
Technical decisions
No Terraform execution, provider calls or AWS credentials. Analysis errors and incomplete coverage lead to REVIEW; strict CLI gating requires --fail-on-review.
Status / limitations
Private beta on Render, not a complete AWS security assessment. Only supported relationships are modeled; dynamic/runtime behavior and unsupported coverage remain limitations.
