Administration via bastion; private workload outbound via NAT.

Problem
Keep a workload off the public internet while retaining scoped administration, outbound access and network visibility.
What I built
Original manual AWS lab in August 2025; faithful Terraform reconstruction and security hardening in 2026.
Architecture
Public subnet: bastion and NAT Gateway. Private subnet: workload without a public IP. SG-to-SG SSH, custom NACLs and VPC Flow Logs → CloudWatch.
Implementation
IMDSv2, scoped security groups, subnet filtering, logging and offline Terraform tests with a mocked provider, TFLint, Checkov, ShellCheck and CI.
Technical decisions
Console → Terraform; private key on bastion → key stays on workstation with ProxyJump; broad configuration → scoped hardening; manual checks → automated validation.
Status / limitations
The original 2025 AWS lab is distinct from the 2026 reconstruction. Current Terraform has offline validation, not a fresh AWS deployment. The advanced security architecture is a Terraform-validated design, not deployed; offline checks do not prove live routing.
